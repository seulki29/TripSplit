# UX Polish Implementation Plan (Plan 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax. Task 7 (E2E + deploy) is controller-run — do NOT dispatch it to a subagent.

**Goal:** Korean error messages everywhere, no stuck loading states, in-flight feedback on every submit, Enter-to-submit, accessible modals, and the 컴펌→확정 copy fix.

**Architecture:** Frontend-only (no backend/deploy change). Error translation is centralized in `api.js` via a new `errorMessages.js` map, so all ~26 error-display sites improve at once. Modal a11y lives in `ui.js`. Remaining per-view polish is grouped by file to avoid cross-task conflicts.

**Tech Stack:** vanilla ES modules, node:test.

**Spec:** `docs/superpowers/specs/2026-07-28-ux-polish-design.md`

## Global Constraints

- No backend change; no Cloud Functions redeploy. Frontend suite (`npm test` at repo root) green at every commit.
- Error translation is centralized in `callFunction` (`api.js`) using `public/errorMessages.js`; views keep displaying `err.message` (now Korean). Unknown codes → generic Korean fallback. The existing network-error and reload-on-`UNAUTHENTICATED`/`PERMISSION_DENIED` behavior is preserved.
- Submit-state pattern (already used in login.js/admin.js): `btn.disabled = true; btn.textContent = '<progress>';` before the await; restore `btn.disabled = false; btn.textContent = '<label>'` only on the error path (success paths that navigate or close the modal don't restore).
- Enter-to-submit must reuse the same click handler (or a shared submit function) so the disabled-guard prevents double submits.
- Display-only copy change for 컴펌→확정; backend `confirmed`/`confirmExpense` unchanged.
- Category list stays `['숙박','식비','장보기','교통비']`; no build step.

### Task 2: Modal accessibility

**Files:**
- Modify: `public/ui.js`

**Interfaces:**
- Produces: `openModal(title, bodyHTML)` sets `role="dialog"`/`aria-modal`/`aria-label`, focuses the first field, and installs an Escape handler; `closeModal()` removes the Escape handler and returns focus to the opener. Signatures unchanged.

- [ ] **Step 1: Add tests** to `public/test/ui.test.js` (it uses jsdom — follow its setup). Assert: after `openModal('제목','<input id="x">')`, `.modal-box` has `role="dialog"` and `aria-modal="true"`; a `keydown` Escape on document closes it (overlay loses `open`); `closeModal()` is safe when nothing is open.

```js
test('openModal sets dialog a11y attributes and Escape closes it', () => {
  openModal('테스트', '<input id="mx">');
  const box = document.querySelector('.modal-box');
  assert.equal(box.getAttribute('role'), 'dialog');
  assert.equal(box.getAttribute('aria-modal'), 'true');
  const overlay = document.getElementById('modal-overlay');
  assert.ok(overlay.classList.contains('open'));
  document.dispatchEvent(new window.KeyboardEvent('keydown', { key: 'Escape' }));
  assert.ok(!overlay.classList.contains('open'));
});
```

- [ ] **Step 2: Run → FAIL.**

- [ ] **Step 3: Implement in `public/ui.js`.** In `getModalRoot`, add `role="dialog"` and `aria-modal="true"` to the `.modal-box` markup. Add a module-level `let lastFocused = null; let escHandler = null;`. Update `openModal`:

```js
function openModal(titleHTML, bodyHTML) {
  const overlay = getModalRoot();
  const box = overlay.querySelector('.modal-box');
  overlay.querySelector('.modal-title').textContent = titleHTML;
  box.setAttribute('aria-label', String(titleHTML));
  overlay.querySelector('.modal-body').innerHTML = bodyHTML;
  overlay.classList.add('open');

  lastFocused = document.activeElement;
  escHandler = (e) => { if (e.key === 'Escape') closeModal(); };
  document.addEventListener('keydown', escHandler);

  const first = overlay.querySelector('.modal-body input, .modal-body select, .modal-body textarea, .modal-body button');
  if (first) first.focus();
}
```

and `closeModal`:

```js
function closeModal() {
  const overlay = document.getElementById('modal-overlay');
  if (overlay) overlay.classList.remove('open');
  if (escHandler) { document.removeEventListener('keydown', escHandler); escHandler = null; }
  if (lastFocused && typeof lastFocused.focus === 'function') { lastFocused.focus(); lastFocused = null; }
}
```
